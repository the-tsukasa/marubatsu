# Marubatsu (○×ゲーム)

SwiftUI + SpriteKit 制作のシンプルな○×ゲーム。複数のゲームモード、AI対戦、アニメーション効果を搭載。

A simple Tic-Tac-Toe game built with SwiftUI and SpriteKit.

## ✨ 特徴 / Features

- **👥 対人戦 (PVP)**: 2人対戦モード / Two-player mode
- **🤖 AI対戦 (PVA)**: AI と対戦 / Play against AI
- **👑 AIゴッド (GOD)**: AI同士の対戦観戦 / Watch AI vs AI
- スムーズなアニメーションと効果音 / Smooth animations & sound effects

## 🏗️ 構成 / Architecture

- `ContentView.swift`: 画面切替 / Scene management
- `GameScene.swift`: 盤面処理 / Game board logic
- `AIEngine.swift`: AI ロジック / AI implementation
- `TouchHandlers/`: タッチ処理システム / Touch handling system
